This is not a conventional portfolio. It is a terminal-inspired digital profile that blends engineering precision with modern UI design, giving visitors a fast, interactive view of my experience in DevOps, automation, and cloud-focused software delivery.

---

## ⚡ Key Features

- Interactive terminal-style homepage where users can explore my profile through commands like `whoami`, `ls`, and `cat about.txt`
- Project showcase designed like operational logs and engineering artifacts rather than generic cards
- Skills and capabilities presented as a structured inventory for quick scanning
- Responsive, polished interface built with a green-on-black terminal aesthetic to reflect a systems-first identity
- Clean React + TypeScript architecture with reusable UI components and modern styling patterns

## 🚀 Getting Started

To run this portfolio locally:

```bash
# 1. Clone the repository
git clone https://github.com/lasinduaz/lasindus-s-Portfolio.git
cd lasindus-s-Portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```
