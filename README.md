# Lasindu's Portfolio

A personal portfolio focused on DevOps engineering, automation, and cloud infrastructure projects.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Vitest

## Development

```sh
npm install
npm run dev
```

## Build and Preview

```sh
npm run build
npm run preview
```

## Testing

```sh
npm run test
```

## Notes

- Static assets are served from the Vite base path.
- Resume file is available at public/resume.pdf.
